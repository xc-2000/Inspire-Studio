The local seed organizes titles, tags and excerpts. Migration V32 retains the
existing prompt text and original source URLs, and replaces repository categories
with use-based categories. Source information is retained internally; the prompt
cards, details and category selector do not display repository attribution.
Keep these notices with redistributed copies of the collection.

The older seed also includes 494 entries from
`davidwuw0811-boop/awesome-gpt-image2-prompts`. No declared license was found in
that repository on the verification date. V32 disables only its untouched seed
entries; it does not delete them or change records created or edited by an
administrator. They are not part of the default licensed selection.

The counts above describe the original selected seed, not a live inventory.
Administrators can continue to edit, add or disable records independently.
